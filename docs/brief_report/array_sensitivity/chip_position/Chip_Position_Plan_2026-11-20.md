# Post hoc analysis of discovery array position

Recorded 20 November 2026 after the original signature and stricter-filter results were known and before the checks below were evaluated.

1. Hold the all-six discovery QC universe and 0.05 effect-size cutoff fixed. Recompute the beta difference after omitting each discovery array in turn. Record signature size, gain share and overlap. Recalculate the two fetal direction ORs with the original donor bootstrap and residual permutations. Use the same donor draws for the paired comparison with the original six-array OR.
2. On the original signature, orient each CpG by its archived beta sign. Summarize the median adjacent and endpoint beta differences, the fraction with a positive endpoint change within each treatment group, and the fraction strictly monotone in the archived direction in both groups. Summarize the full array and the gain and loss subsets separately. Use all 36 within-group row orders as a descriptive reference for strict monotonicity. Group membership and the signature are fixed in that comparison.
3. Compare with an independent technical-replicate EPIC v1 row reference if public data allow it. Use a contrast of R05–R07 versus R02–R04 within matched pooled subjects from the Butler et al. study if the required rows are available. Define the susceptible group by the top decile of absolute reference effect among shared callable probes. Compare the signature with background on shared callable chromosome, Infinium design and mean-beta strata. Assess chromosome-level direction and the cross-study direction association separately. Use Hecker et al.'s published high slide-effect set as a secondary comparison if available. It measures between-slide effects.

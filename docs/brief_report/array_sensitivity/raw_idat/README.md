# Raw GSE157078 IDAT quality control and sensitivity

The dated plan records the post hoc contrasts. The recreated raw-IDAT signature exactly reproduced the archived signature on the original GEO QC support. The donor-based estimates reuse the primary fetal inputs, models, and resampling settings.

## Reproduction

Use the [GSE157078 GEO sample SOFT](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE157078&targ=gsm&form=text&view=brief) and the raw signal matrix and EPIC annotation documented in the [original signature analysis](../signature_checks/README.md). Verify the twelve downloaded GEO files against `IDAT_SHA256SUMS.txt`. The R analysis used R 4.5.2, minfi 1.54.1, illuminaio 0.50.0, the EPIC manifest 0.3.0, the EPIC hg19 annotation 0.6.0 and ewastools 1.8.2 at commit `d7d0a3295177b2528248966012f635be881f78ab`. See `R_session.txt` for the full session.

Use the pinned Python environment, the fetal cache, and the [Brief Report source at commit 4768daa](https://github.com/Ghostneuron/DNMT3L_Neuron/tree/4768daae4bb0c5f647602d5a80e3c24c7c93a600/docs/brief_report) or the extracted prior combined compendium. Use the adjacent `signature_checks/run_signature_sensitivity.py` for `signature_module`.

```sh
python get_idats.py "$geo_sample_soft" "$idat_dir"
Rscript process_idats.R "$idat_dir" array_positions.tsv "$out" "$scratch"
python compare_preprocessing.py "$scratch/idat_beta.tsv.gz" "$geo_signals" "$epic_annotation" "$signature_module" "$compendium" "$fetal_cache" "$out"
python summarize_global_mean_delta.py "$scratch/idat_beta.tsv.gz" "$geo_signals" "$out/global_mean_delta.tsv"
python draw_array_qc.py "$out" "$qc_pdf"
```

`idat_beta.tsv.gz` is a local intermediate. It stores raw, background-only Noob, and dye-corrected ssNoob beta values for the same samples and is regenerated by the R script. All beta values use the same offset of 100. The original GEO QC universe required detection P ≤ 0.01 in all six arrays and a mapped EPIC probe. The stricter support added the all-six ewastools IDAT detection filter. Both scopes hold the callable probe universe fixed across comparisons, including array omissions.

The per-array summaries apply detection P > 0.01 or missing values as failures, with autosomal and all-CpG denominators shown. The control-ratio flags are ewastools flags under its defaults for non-FFPE samples. Scanner timestamps were transcribed from the red IDAT scan records, with barcode and position independently checked in both channels. They describe the scan sequence and provide no record of wet-lab order.

`preprocessing_pca.tsv` gives the first two components of the six-array sample Gram matrix with and without the common probe means removed. The signs are oriented toward increasing row. The uncentered first component captures the largely shared CpG profile, so its percentage has a different denominator from the centered PCA.

## Main results

On the original GEO support, raw IDATs reproduced 15,602 calls, 88.6% gains. Background-only Noob gave 20,735 calls, 89.9% gains. Dye-corrected ssNoob gave 8,742 calls, 48.6% gains. Excluding Z1 after dye correction gave 49.4% gains. The corrected fetal ORs were 2.41 and 2.36 with donor permutation P values of 0.428 and 0.336. The paired donor-bootstrap intervals for corrected versus raw ORs included 1. The additional IDAT detection filter gave similar point estimates. Table S6 and the standalone row-wise QC PDF summarize the results. Chip position, scan order and treatment coincide in these six arrays.

Across the same 865,743 probes, the global mean overexpression-minus-control beta difference was +0.011882 for raw beta, +0.011719 after background-only Noob, and +0.001035 after ssNoob dye correction. `global_mean_delta.tsv` reports the full-precision values, and `summarize_global_mean_delta.py` regenerates them from the local IDAT beta intermediate and public GSE157078 signal matrix. This descriptive summary is not a differential-methylation test and does not separate treatment from chip position or scan order.

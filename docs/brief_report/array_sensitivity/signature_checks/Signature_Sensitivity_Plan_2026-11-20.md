# Post hoc signature sensitivity plan

Recorded on 20 November 2026, after the primary and donor sensitivity results were known and before computing this analysis.

- Reconstruct the archived GSE157078 signature from the public signal matrix. Use beta = M/(M + U + 100), require detection P ≤ 0.01 on all six arrays, and apply the original platform annotation requirement and absolute mean beta-difference cutoff of 0.05. Verify that the reconstructed observed probe IDs and signs match the archived 15,602-site list.
- Enumerate each distinct unordered 3-vs-3 partition once, orienting the contrasts so that SAMPLE 4 is always in the putative overexpression arm. Report signed counts and overlap with the observed list. The nine mixed-label partitions describe the threshold's sensitivity to label assignment. They can still carry diluted treatment or technical differences, so their counts do not estimate a probe-level false discovery rate.
- Apply three nested checks relative to the archived effect-size signature: complete separation of all three values in each group, nominal limma P < 0.05, and limma Benjamini–Hochberg q < 0.05. Use two-sided moderated t-tests on logit-transformed beta values (clip at 10⁻⁶ and 1−10⁻⁶) with mean-dependent empirical Bayes moderation. Adjust over all QC-eligible discovery probes before intersecting with the effect-size signature. Keep the archived beta direction. Record any technical structure evident from the deposited sample metadata and qualify the group-only analysis accordingly.
- In the two fetal cohorts, hold the original donor models, quality filters, probe strata and external beta signs fixed. Recalculate the stratified OR for each subset, use the same 2,500 donor bootstrap draws to compare paired ORs with the original signature, and repeat the original two-sided donor residual permutation for each estimable subset. These analyses condition on the GSE157078 arrays and are exploratory.

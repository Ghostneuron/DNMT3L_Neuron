# Dated sensitivity plan for the DNMT3L fetal brain Brief Report

**Recorded November 20, 2026 (America/Los_Angeles), before evaluating the two sensitivity analyses below.** The v1.2.0 donor-level results and the audit diagnostics were already known. This is a post hoc sensitivity plan. The public v1.2.0 archive and its primary estimates are the comparison baseline.

## Frozen inputs and primary statistic

Keep the GSE157078 DNMT3L probe calls, donor-region reconstruction, quality-filtered CpGs, cohort-specific regression design, and Mantel–Haenszel (MH) directional odds ratio (OR) used in the Brief Report. The original strata are chromosome, island category, Infinium design type and bins of pooled unlabeled fetal beta values. Test the two cohorts separately. GSE74486 uses the normalized matrix before ComBat with age and sex in the regression. GSE73747 uses the signal-derived beta matrix with age, sex and brain region. Batch covariates remain unavailable in the checked public fetal sample metadata. The published donor bootstrap remains the reference for the primary cohort intervals.

## Sensitivity A. Donor-level permutation

- Primary permutation method: Freedman–Lane reduced-model residual permutations. Remove the fitted nuisance effects (intercept, age and sex, plus region in GSE73747); apply the same permutation to every CpG, move whole donor residual vectors within sex and region-availability blocks, and refit the original diagnosis regression. Regions from a paired donor travel together in matched order. Use 9,999 draws and the two-sided statistic `|log(MH OR)|`, with a plus-one Monte Carlo tail probability. The fixed external signature and the frozen probe strata are reused throughout.
- Supplementary contrast: shuffle donor diagnosis labels within the same blocks, preserving the observed number of DS donors per block. Refit the model with age, sex and region as applicable. Enumerate all permitted assignments when there are at most 10,000 (including the observed assignment), otherwise use 9,999 Monte Carlo draws and the plus-one rule. Distinguish enumerating assignments from the validity of the null. Label permutation requires diagnosis-label exchangeability within the blocks. Residual permutation is approximate after estimating nuisance effects and requires residual exchangeability. Unmeasured batch or differences in variability can compromise both.
- Report both results by cohort, valid draw counts, null quantiles, point ORs and the original leave-one-donor-out ranges. Keep the genome-wide DS null interpretation separate from a specificity claim. The matched-CpG panel comparison is descriptive for the observed donors and is omitted from the abstract.

## Sensitivity B. Independent Spiers maturation reference

- Use the public GSE58885 Illumina 450K normalized beta matrix and donor-level sex and age metadata. Estimate each probe's continuous beta change per 28 post-conception days from a linear model with sex as a covariate. Estimate primary slopes in the externally defined 70–112 days post-conception window (the 12–18 gestational-week overlap under a conventional two-week offset). Repeat using 84–126 days to assess sensitivity to that offset, and the full published age range to assess window dependence. These are reference windows for the age slopes. The DS donor samples remain as defined in the original analysis. Require at least 20 external samples with an age span of at least 28 days per window. Use probes with finite reference beta in all donors in the respective reference window.
- Restrict each DS analysis to probes with an available slope in that window and compare the unadjusted and adjusted ORs on exactly the same CpGs. Within the original CpG strata, center the continuous Spiers age slope. Use the whole jointly eligible array to estimate a common within-stratum linear projection of each fitted DS effect onto that centered slope. Subtract the fitted slope term and recompute the MH OR for residual DS-effect direction at the fixed DNMT3L gain and loss probes. An equivalent linear transformation of the DS matrix permits refitting in each bootstrap draw. Pair the baseline and adjusted estimates on the same 2,500 donor-bootstrap draws and summarize the adjusted OR and ratio of adjusted to baseline ORs with percentile intervals. Reference slopes are held fixed. Also report the point OR for DNMT3L direction versus Spiers age-slope direction in the same probe strata.
- Analyze independent reference windows separately. Report reference donor counts, age ranges, shared eligible array and signature sizes. Interpret attenuation or persistence in terms of overlap with normal developmental methylation. The cross-sectional bulk reference does not separate individual developmental rate, cell composition or causal DNMT3L dosage.

## Interpretation and reporting

Use replication across cohorts and the paired uncertainty to judge the sensitivity results. Report all specified windows and both permutation procedures, including any discordance. No new gene-specific causal claim, pooled estimate or combined test is planned. Document unexpected input or design deviations alongside the results. Keep the frozen v1.2.0 archive traceable and add the new results to the journal supplement.

# DNMT3L Neuron Zenodo Research Compendium

This archive is a manuscript-facing companion to the code release for the project
"Public multi-omic evidence maps DNMT3L-linked methylation and STAT/TF hypotheses
in Down syndrome neurodevelopment."

## Contents

- `code/`: GitHub-ready analysis code, configuration files, release metadata, and
  reproducibility documentation.
- `manuscript/`: final manuscript-facing document files and graphical abstract.
- `final_figures/`: final assembled main and supplementary figure files used for
  manuscript preparation.
- `supplementary_tables/`: supplementary tables supporting the manuscript.
- `source_figure_panels/`: source figure panels generated by the analysis scripts.
- `derived_results/`: compact derived result tables, BED files, logs, and summaries
  used to construct the manuscript figures and supplementary tables.
- `zenodo_compendium_manifest.tsv`: file-level manifest with byte counts and SHA256
  checksums for the archived files.

## Exclusions

The archive intentionally excludes raw downloaded GEO payloads, controlled-access
dbGaP data, copyrighted literature PDFs, software caches, rendered manuscript QA
pages, and large intermediate HOMER sequence/background files. These exclusions
keep the deposit redistributable and focused on code, derived results, figures,
and manuscript-supporting tables.

Raw public data sources and accession-level provenance are described in
`code/docs/DATA_SOURCES.md` and `code/docs/REPRODUCIBILITY.md`.

## Relationship To GitHub

The `code/` directory mirrors the GitHub-ready software release. For normal public
version control, use the separate `GitHub_Zenodo_Code_Release_20260620` folder or
the GitHub repository generated from those files. This research compendium is
intended for Zenodo or a journal supplementary-data deposit.

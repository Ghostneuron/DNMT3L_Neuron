# Release Notes for Version 1.1.0

2026-11-20

- Added the stratified human CpG concordance benchmark, including the leave-one-chromosome-out sensitivity summary.
- Added the Dp(10)1Yey and Dp(16)1Yey comparison on an identical CpG set. The source profiles used one newborn animal per genotype.
- Recalculated discovery scores using gene-level GSE268951 expression and assessed weight and component sensitivity. Historical manually prioritized candidates are identified in the audit table.
- Added the R1 figure-generation script, the core dataset manifest, and frozen summary tables.

The human benchmark is conditional on the archived DNMT3L-sensitive probes. The outputs describe locus-level agreement and candidate prioritization. A DOI should be cited only once a matching compendium record is published.

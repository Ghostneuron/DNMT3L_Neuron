# Release Notes: 2026-06-20 Code Preparation

Prepared a code-focused GitHub/Zenodo release structure for the DNMT3L Neuron project.

## Added

- GitHub/Zenodo-facing README.
- MIT code license.
- `CITATION.cff`.
- `.zenodo.json`.
- `CODE_AVAILABILITY.md`.
- `requirements.txt` and `environment.yml`.
- Reproducibility and data-source documentation.
- Release checklist.
- Code/script manifest generator.

## Excluded From Version Control

- Downloaded input data.
- Controlled-access data.
- Derived result caches.
- Generated figures.
- Manuscript drafts and rendered manuscript pages.

## Notes

The release is intended as a software/code archive. It documents how to re-create analyses from public accessions and controlled-access resources where available, but it does not redistribute large or restricted datasets.
